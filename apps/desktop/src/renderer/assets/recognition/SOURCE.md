# Recognition artwork source

The rendered 3D objects in this directory come from the original **3Dicons** pack by
Vijay Verma (`realvjy`). The initial icon set is released under Creative Commons Zero
(CC0) and may be copied, adapted and redistributed without attribution.

- Source: https://3dicons.co/about
- Repository: https://github.com/realvjy/3dicons
- Style used here: dynamic / color PNG

Yuksalish adds its own tier lighting, particles, card material, progress and interaction
effects around these source objects without placing an extra shape behind the render.
