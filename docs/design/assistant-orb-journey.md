# Перелёт орбы ассистента

Одна постоянная орба перемещается из верхней кнопки в мини-чат за 420 мс.
Для чата с историей она занимает место слева от названия ассистента;
для пустого — центр приветствия над «С чего начнём?». Второй орбы в заголовке
пустого чата нет. После посадки поверхность чата раскрывается из орбы за 320 мс.

Первое сообщение гасит приветствие за 180 мс и переносит орбу в заголовок;
название плавно освобождает место. Закрытие возвращает её в верхнюю кнопку.
Shader, палитра, толщина кольца и тень сохранены. Текст не масштабируется.
Перелёт отменяется при смене сценария; resize, zoom, reduced motion и forced colors
дают итоговую позицию без декоративного движения. Скрытие вкладки завершает
переход, а чужое модальное окно блокирует кнопку и останавливает орбу.

Изменения только в renderer. Существующие голосовые промпты, подготовка форм,
история и черновики сохранены; миграции и обновление API не нужны.

## Проверка

`assistant-orb-journey.test.tsx` проверяет порядок перелёт → раскрытие, посадку,
ожидание загрузки, отмену и reduced motion/resize. `YuksalishAssistant.test.tsx`
проверяет совместимость с действиями, голосом, перепиской и фокусом.

Визуальный стенд `/qa/assistant-empty-orb.html` использует настоящие компоненты,
но перехватывает запросы: сообщения остаются в памяти страницы, ответ тестовый.
Доступны пустой чат и чат с историей. Это не проверка реального Gemini.
Скриншоты хранятся только в игнорируемом `tmp/assistant-orb-journey`.
Для установленного EXE потребуется отдельная сборка; GitHub push её не обновляет.
