# Перелёт орбы ассистента

Одна постоянная орба перемещается из верхней кнопки в мини-чат за 300 мс.
Для чата с историей она занимает место слева от названия ассистента;
для пустого — центр приветствия над «С чего начнём?». Второй орбы в заголовке
пустого чата нет. Сразу после посадки поверхность чата раскрывается из орбы за
220 мс: круглая маска растёт от размера орбы до самого дальнего угла окна.
Центр маски совпадает с центром орбы, включая масштабирование интерфейса;
раскрытие идёт во все стороны одновременно, без отдельной паузы и общего fade.
Перелёт и маска запускаются в одном кадре: задержка маски равна длительности
перелёта, а не добавляется после него. На кадре посадки сама анимация делает
маску видимой, не ожидая React-переключения фазы. При отсутствии перелёта
задержки нет. Кривая открытия `cubic-bezier(.4, 0, .8, 1)` не даёт орбе визуально
замереть задолго до окончания перелёта; остальные переходы сохраняют свой easing.

Первое сообщение гасит приветствие за 180 мс и переносит орбу в заголовок;
название плавно освобождает место. Закрытие возвращает её в верхнюю кнопку.
Эти перелёты сохраняют прежнюю длительность 420 мс.
Shader, палитра, толщина кольца и тень сохранены. Текст не масштабируется.
По уточнению владельца 7 октября во время перелётов только орба получает мягкий
motion blur: 0 → до 2.4 локальных px → 0, слабее при коротком перемещении.
На посадке, при отмене и мгновенном переходе фильтр сбрасывается. Поверхность
окна и текст не размываются. Маска приветствия оставляет 48 локальных px вокруг
орбы для тени, но обрезает её у границ области переписки при прокрутке.
Перелёт отменяется при смене сценария; resize, zoom, reduced motion и forced colors
дают итоговую позицию без декоративного движения. Скрытие вкладки завершает
переход, а чужое модальное окно блокирует кнопку и останавливает орбу.

Изменения только в renderer. Существующие голосовые промпты, подготовка форм,
история и черновики сохранены; миграции и обновление API не нужны.

## Проверка

`assistant-orb-journey.test.tsx` проверяет порядок перелёт → раскрытие без таймера,
длительность, общий центр и покрытие углов маской при CSS zoom, посадку,
ожидание загрузки, отмену раскрытия/повторное открытие и reduced motion/resize. `YuksalishAssistant.test.tsx`
проверяет совместимость с действиями, голосом, перепиской и фокусом.

Визуальный стенд `/qa/assistant-empty-orb.html` использует настоящие компоненты,
но перехватывает запросы: сообщения остаются в памяти страницы, ответ тестовый.
Доступны пустой чат и чат с историей. Это не проверка реального Gemini.
Скриншоты хранятся только в игнорируемом `tmp/assistant-orb-journey`.
Для установленного EXE потребуется отдельная сборка; GitHub push её не обновляет.
