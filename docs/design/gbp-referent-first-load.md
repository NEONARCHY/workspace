# GBP и первое открытие AI Referent

В курсах вместо CNY запрашивается GBP из того же официального источника. Меняется именно набор валют сервиса, включая курс и изменение за одну единицу; название не подменяет значение CNY. Контракт ответа совместим, миграция данных не требуется. Конвертер проверен на синтетическом курсе GBP.

## Причина появления промежуточных кнопок

При первоначальном входе выбран реестр «Входящие», но его видимость определяется асинхронно. Раньше до ответа о доступе уже отображалась неполная навигация без выбранной вкладки. Теперь эта панель ждёт результата проверки. Независимый вход в исходящие остаётся доступен сразу. При ошибке проверки доступна навигация исходящих и повторная проверка входящих.

Кнопки реестра с явно переданным ещё не готовым контейнером больше не появляются временно внутри содержимого перед переносом в панель. Самостоятельное использование кнопок без контейнера сохранено. Это исправление жизненного цикла интерфейса; зависание shimmer не воспроизведено.

## Проверка в браузере

`scripts/ui-consistency-smoke.cjs --referent-initial` задерживает ответы о видимости реестров и полномочиях отдельно. Все ответы синтетические, рабочая переписка не используется. Режим `--before` подставляет исходный компонент из базового коммита `039acd2901209fbd3940f79f1d95baf5358370b5`.

До исправления: 1440 px в обеих темах — при незавершённой проверке доступа видна неполная панель. После: 1440 px в обеих темах и 1024/390/320/720 px в тёмной теме — неполная панель отсутствует, после ответа выбраны входящие, кнопки находятся в конечном контейнере, переполнения страницы и ошибок браузера нет. Дополнительно на 1440 px в обеих темах проверены выбор GBP, отсутствие CNY и пересчёт суммы.

Игнорируемые снимки относительно корня рабочего дерева:

- `tmp/gbp-referent-initial/{before,after}/pending-{theme}-{width}.png` — ожидание доступа;
- `tmp/gbp-referent-initial/{before,after}/visibility-{theme}-{width}.png` — доступ загружен, полномочия ещё загружаются;
- `tmp/gbp-referent-initial/{before,after}/ready-{theme}-{width}.png` — готовый раздел;
- `tmp/gbp-referent-currency/after/gbp-{theme}-1440.png` — проверка GBP на тестовых курсах.

## Совместная работа и выпуск

Открытый PR #275 также затрагивает компонент AI Referent и его тесты. Эта правка ограничена первоначальной навигацией, обработкой ошибки проверки доступа и регрессионными тестами; формы писем и рассылки не меняются. После первого объединения второй PR должен синхронизироваться с main и повторить проверки.

Для замены валюты требуется выпуск API вместе с web/desktop. Одна пересборка web не меняет список валют, возвращаемый старым API. Миграции нет. TEST `https://192.168.31.176:8443/` при проверке недоступен по TCP, Docker на этом ПК не запущен и `.env.lan` в рабочем дереве отсутствует; обновление сайта не выполнено. Офисный сервер не изменялся.
