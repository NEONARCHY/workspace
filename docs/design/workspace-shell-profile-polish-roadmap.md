# Доработка оболочки, профиля и рабочих досок

**Ветка:** `codex/workspace-ui-access-avatars`
**Статус:** завершено
**Правило готовности:** пункт отмечается завершённым только после проверки кода и целевого сценария.

## Пакеты работы

- [x] **WS-P1 — Полномочия администраторов.** `admin` и `superadmin` имеют полный доступ к модулям и защищённым действиям, включая решения по заявкам; ограничения целостности системы и аудит сохраняются.
- [x] **WS-P2 — Адаптивный sidebar.** Sidebar не прокручивается; доступные по высоте пункты остаются на месте, остальные попадают в кнопку «Ещё» и доступный mini-drawer рядом с панелью.
- [x] **WS-P3 — Профиль и настройки.** Меню профиля гарантированно закрывается при переходе в настройки и не остаётся поверх drawer.
- [x] **WS-P4 — Табличные страницы.** Исправлено отображение выбора размера страницы и удалён ошибочный визуальный элемент рядом с ним.
- [x] **WS-P5 — Суммы заявок.** Изменившиеся цифры плавно прокручиваются сверху вниз как механический счётчик; анимация локальная, оптимизированная и отключается при `prefers-reduced-motion`.
- [x] **WS-P6 — Общий drag-and-drop.** Drag overlay совпадает с исходной карточкой по геометрии и оформлению; добавлен лёгкий наклон по направлению движения без покадрового React-render.
- [x] **WS-P7 — Аватары.** Пользователь может загрузить изображение до 15 МБ; тип и размер проверяются клиентом и сервером, файл хранится в серверном объектном хранилище и защищён авторизацией.
- [x] **WS-P8 — Отсутствия.** Раздел приведён к пространственной дизайн-системе Workspace: ясная композиция, контекстный drawer, согласованные кнопки, состояния и анимации.
- [x] **WS-P9 — Проверка и поставка.** Пройдены целевые тесты, lint/typecheck, Python-проверки по изменённым слоям и ручная проверка локального web; подготовлены коммит и ссылка для Pull Request.

## Контрольные сценарии

1. Администратор видит все модули и может выполнить допустимое действие над любой заявкой; сервер всё равно проверяет валидность текущей стадии.
2. При уменьшении высоты окна sidebar не получает scrollbar и не выталкивает профиль/системные действия за экран.
3. Переход из меню профиля в настройки закрывает исходное меню до появления панели настроек.
4. Смена размера страницы не показывает лишнюю кнопку очистки и остаётся доступной с клавиатуры.
5. Сумма и DnD остаются читаемыми при reduced motion и не создают постоянную нагрузку на renderer.
6. Аватар больше 15 МБ или файл не-изображение отклоняется; корректный аватар сохраняется после повторного входа.
7. Создание, просмотр и решение по отсутствию работают из обновлённого интерфейса без изменения бизнес-правил.
