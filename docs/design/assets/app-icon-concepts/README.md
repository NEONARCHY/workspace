# Варианты иконки Yuksalish Workspace

Концепции предназначены для выбора направления. Они используют только фирменные
цвета `#293A55`, `#0091A8`, белый и нейтральные оттенки интерфейса. Полный wordmark
не помещается в системную иконку, поэтому варианты развивают букву Y, восходящий
штрих логотипа и идею рабочего маршрута.

1. **Rise** — наиболее близкий к основному логотипу: Y и фирменный восходящий штрих.
2. **Route** — спокойная светлая иконка с направлением рабочего процесса.
3. **Workflow** — Y из связанных точек для задач, команд и согласований.
4. **Forward** — более динамичный абстрактный знак роста и движения вперёд.

SVG не заменяют оригинальный логотип и не должны использоваться как wordmark.
Для каждого варианта приложены PNG-превью 512 px и multi-resolution Windows `.ico`
с размерами 16, 20, 24, 32, 40, 48, 64, 128 и 256 px. Все варианты проверены в
малых размерах; до выбора ни один из них не подключён к Electron builder.

Предварительная рекомендация: **Rise** лучше всего сохраняет узнаваемость бренда,
а **Forward** чище всего читается в системной панели при 16-20 px.
