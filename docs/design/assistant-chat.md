# Чат ассистента — 4 октября 2026

## Результат

Один чат для компактного и развёрнутого окна: общий черновик, история,
выбранная модель, вложение и цитата сохраняются при смене размера. Мини-окно
шириной до 460 px; на экране до 600 px занимает доступную область. Широкий
режим ограничивает строки и редактор общей колонкой до 800 px.

| Было | Стало | Зачем |
| --- | --- | --- |
| Две рамки ввода, тесный ряд с длинным пояснением модели | Один редактор, компактный выбор режима, отдельные понятные кнопки | Убрать вложенные контуры и перекрытие кнопки отправки |
| Шаблоны преимущественно для справки и текстов | Четыре основных действия: задача, проект, поездка, отсутствие | Показать главную рабочую роль ассистента |
| «Как подготовлен ответ» под каждой репликой | Только ответ, ссылки на доступные записи и содержательный черновик | Не загромождать переписку служебным блоком |
| Мгновенная смена размера, долгий каскад абзацев | Реальная геометрия 220 мс, короткое появление текста 180 мс | Плавность без масштабирования букв и задержки действий |

Gilroy, фирменные navy/turquoise, мягкие градиенты быстрых действий,
спокойная светлая область переписки. Главная кнопка отправки navy; цвет и
обводка показывают фокус всего редактора. Общий стиль обычных полей больше
не применяется к внутреннему textarea ассистента. Подготовленные записи
показывают название типа, известные поля и явный статус «ещё не создано».

## Взаимодействия

- Paste файлов работает только в редакторе; обычная вставка текста нативная.
  Drop принимается в шапке, переписке и редакторе обоих размеров окна.
- Одна проверка для всех способов: один непустой поддерживаемый файл до 5 МБ,
  имя до 160 символов. Множественный/недопустимый файл не заменяет прежнее вложение.
  При ответе и голосовом вводе добавление заблокировано; отправка не автоматическая.
- Содержимое вложения отправляется модели только с текущим запросом и может
  использоваться для подготовки рабочей записи по явной просьбе пользователя.
  В истории хранится имя, не сам файл. Вложение не является инструкцией системе.
- Enter отправляет, Shift+Enter добавляет строку. Долгий ввод имеет ограниченную
  высоту с учётом экрана; на очень тесном экране низ остаётся достижимым прокруткой.
- Готовый черновик не перехватывает следующий общий вопрос. Для правки есть
  «Уточнить черновик»; подготовку можно отменить. Сохранение/отправка выполняются
  только штатной формой Workspace после подтверждения, с прежними правами.
- Голос, цитирование, полезные ссылки на записи и поведение орбы сохранены.

## Motion и границы

Появление окна/расширение — 220 мс, новых ответов — 180 мс с задержкой
не более 120 мс. Вложение и быстрые действия появляются за 180 мс; область
drop — 160 мс. Никакого scale текста, фонового blur или новой библиотеки.
Быстрое повторное разворачивание начинается с текущих видимых размеров;
resize экрана, смена системных предпочтений и закрытие отменяют переход.
Reduced motion и forced colors отключают декоративные переходы.

Использованы указания [Emil Design Engineering](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md),
полученные через Lazyweb, для короткого, прерываемого motion и доступных контролов;
палитра и композиция подчинены существующему Workspace. Прежняя просьба владельца
о плавном изменении размеров применена к реальной геометрии мини/макси, а не
к увеличению скриншота содержимого. Новая зависимость не добавлена.

## Проверено / ограничение

- TypeScript, ESLint, Ruff и строгий mypy; 83 renderer-теста в восьми файлах,
  41 Python-тест ассистента, включая права, общий вопрос, вложение и отказ провайдера.
- Браузер: мини/макси на 1440×900, 1024×768, 640×480, 360×640, 320×568;
  увеличение интерфейса 200%, одна рамка редактора, доступные кнопки, paste/drop,
  восстановление после ошибки, промежуточный кадр изменения размера.
- Формы задач, проектов, поездок и больничного открыты с перехваченными ответами;
  проверены реальные заполненные поля и отсутствие бизнес-записей.

  интерфейс не может исправить отказ Google. Для реальных ответов и новых
  ИИ-черновиков нужно восстановить доступ проекта у провайдера. Интеграция модели
  подготовлена, но успешная живая генерация не подтверждена.
- Обновляются только API и web тестового LAN; Alembic head до изменения —
  `0073_project_hub_chats`, новых миграций нет. Office-сервер, БД, worker и
