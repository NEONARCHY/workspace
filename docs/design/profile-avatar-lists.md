# Фотографии сотрудников в рабочих списках

## Изменение

«Команда в работе», таблица сотрудников, состав подразделения и сводка/таблица эффективности используют общий `ProfileAvatar` вместо отдельного компонента инициалов. Размеры, сетки, ссылки на профиль и действия управления сохранены. Компонент принимает только идентификатор, имя и версию фотографии; загрузка остаётся через существующий защищённый маршрут, а изображения кэшируются по сотруднику и версии. Без фотографии, токена или при ошибке загрузки показываются инициалы.

После успешной загрузки в настройках событие `yuksalish:profile-avatar-changed` обновляет уже открытые экземпляры того же сотрудника. Ошибка загрузки не отправляет это событие. Более новая версия из серверных данных имеет приоритет над локальным обновлением; устаревший ответ изображения не заменяет новое фото.

## Совместимость

Справочник, присутствие и эффективность дополнительно возвращают `avatarVersion` из уже существующего `users.avatar_updated_at`. Изменения роли, статуса и принадлежности сохраняют это поле в ответе. Личная и общая эффективность возвращают одинаковые сведения о сотруднике; методика, показатели и права не меняются.

Новая миграция для аватарок не нужна. Для существующих записей достаточно обновить API и web/desktop. Старые клиенты игнорируют дополнительное поле; новый клиент с прежним API безопасно показывает инициалы, но не может получить отсутствующую в ответе версию. Самостоятельная загрузка чужих фотографий без авторизации не добавлена.

## Проверка

- Целевые Vitest-тесты: общий компонент (кэш, ошибка, смена версии, устаревший ответ, обновление после загрузки), четыре списка, настройки профиля и участники реакций.
- PostgreSQL-регрессии дополнены проверками версии в присутствии, справочнике, обновлении сотрудника и эффективности. Для запуска нужна отдельная тестовая база; рабочая база и фотографии не меняются.
- `qa/profile-avatars.html` использует реальные компоненты с двумя вымышленными сотрудниками и перехватывает все API-запросы. «Сменить тестовое фото» и «Ошибка загрузки» работают только в памяти страницы. Рисунок-портрет — синтетическая заглушка, не фото сотрудника.

Проверка 9 октября 2026: 57 целевых тестов и полный набор desktop-тестов (859 прошли, 1 пропущен; 123 файла) прошли. TypeScript, ESLint, Ruff, веб-сборка и release notes прошли. В браузере подтверждено декодирование изображений во всех четырёх разделах, обновление после смены и возврат к инициалам при ошибке. PostgreSQL-тесты не запускались: доступного Python-тестового окружения и отдельной базы нет.

Тестовый LAN-сайт `https://192.168.31.176:8443/` недоступен с текущего ПК: повторная TCP-проверка порта 8443 завершилась неуспешно. Сервер не обновлялся. До фактической проверки обновления сервера локальный стенд не считается рабочей серверной проверкой.
