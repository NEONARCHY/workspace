# Плотность строк и выбор ИИ-модуля — 8 октября 2026

По уточнению владельца вертикальные отступы уведомлений уменьшены с 17 до
13 px, минимальная высота — со 105 до 97 px. В браузерном стенде обычное
уведомление уменьшилось с 132.390625 до 124.390625 px. Размер текста,
кнопки, переносы, статусы и свайп-удаление сохранены; длинное содержимое
по-прежнему определяет высоту, фиксированного ограничения нет.

Строки очереди внимания обзора команды имеют радиус 14 px в обычном
состоянии, при hover и keyboard focus. Наведение меняет только цветовую
подсветку, а не форму или размер строки; декоративный слой наследует радиус.

Группа «ИИ-модули» не является выбранной страницей: `has-active-module`
оставляет слабую подсветку группы без класса `active`. Общая движущаяся
плашка выбирает только видимую активную дочернюю кнопку, а не родительский
trigger или «Ещё». Дочерняя кнопка не рисует вторую подложку поверх индикатора.
После выбора сохраняются раскрытие и DOM кнопок. Сворачивание скрывает
индикатор дочернего раздела; раскрытие размещает его сразу на том же модуле.

При раскрытии группы прежние разделы могут сдвигаться даже в меню фиксированной
высоты. SlidingSegmented наблюдает также за высотой слотов и синхронно обновляет
декоративный слой без React-рендеров на каждом кадре. Только реальная смена
выбранной кнопки использует переход 260 мс. Reduced motion и forced colors
сохраняют системные правила. Реализация движения согласована с PR #120;
сохранение раскрытия согласовано с PR #124. Эти изменения дополняют их, а не
меняют другие параметры оформления меню.

Проверки: регрессии размеров/радиусов, реальный общий компонент навигации с
быстрыми переключениями дочерних модулей, скрытие/повторное раскрытие и
изменение геометрии слота без повторного рендера. Визуальная проверка использует
настоящие компоненты в `qa/team-layout.html`, `qa/page-canvas.html` и
`qa/ai-navigation.html` с синтетическими данными без бизнес-запросов записи.

Результат: 57 целевых тестов (включая настройки, использующие общий индикатор),
ESLint, TypeScript, 15 workflow-тестов, проверка заметок выпуска и web-сборка
прошли. Браузером проверены 1280×720, 1024×768, 640×700, масштаб 200% в обзоре
команды, настоящий hover, быстрые переходы между модулями, сворачивание группы
при выбранном календаре и выбор в компактном popover. Разница координат выбранной
кнопки и индикатора после переходов — 0 px; форма и высота строк команды
при hover не меняются. Артефакты сохранены локально в `tmp/ui-controls/`.
Установленный Electron не пересобирался; гарантия частоты кадров не заявляется.

Затронут только renderer. API, БД, права и рабочие записи не изменяются.
