# Плавное изменение размера окон — 4 октября 2026

Владелец попросил расширять/сужать окно целиком при изменении содержимого,
а не только анимировать появление списка. `DialogResizeMotion` подключён один
раз рядом со `ScrollbarEdges` и распространяется на Fluent DialogSurface и
custom modal `dialog` / `alertdialog` с `aria-modal=true`, а также Fluent PopoverSurface.

| До | После | Зачем |
| --- | --- | --- |
| «Новая группа»: список ЦА/регионов меняет высоту скачком | Рамка и центр окна плавно переходят к естественному размеру | Сохранить пространственную связь при смене списка |
| Другие окна требуют отдельных эффектов | Общий механизм реагирует на фактическую смену размера | Одинаковая скорость и безопасное прерывание |

## Область действия

- Новая группа: ЦА/регионы и поиск, когда меняется высота списка.
- Управление группой: раскрытие прав участника, подтверждения и ошибки.
- Формы и справочники: дополнительные поля/подсказки, ошибки, пустые состояния,
  загруженные сведения, если они действительно меняют размер окна.
- Custom modal-окна с семантической ролью получают то же поведение.
- Выбор ответственного: ЦА/регионы, поиск и обновление справочника плавно
  меняют размер всей поверхности, а не отдельного внутреннего списка.
- Другие Fluent popover получают тот же переход при фактической смене размера.
- Окна с фиксированной геометрией не начинают двигаться при смене внутреннего
  содержимого. Канбан, workflow canvas, обычные страницы и отдельные меню не
  включены в этот механизм. Их собственные анимации сохранены.

Последнее уточнение 4 октября: Fluent PopoverSurface больше не исключается.
Удалён отдельный `useContextMotion` из PersonPicker: теперь размером управляет
только общий observer. Внутренний список сохраняет max-height, прокрутку и
стабильный scrollbar-gutter, а поиск/переключатель остаются снаружи списка.
Сторона PersonPicker выбирается при открытии для полного ограниченного списка;
она не переворачивается на каждом кадре. Для anchored popover общий tween
временно компенсирует translation согласно `data-popper-placement`: верхнее
окно сохраняет нижний край, end-выравнивание — правый. Это устраняет задержку
асинхронного Popper ResizeObserver. После перехода позиционирование снова
полностью принадлежит Fluent/Popper; нет покадровых React-render или второго RAF.
Доступное место PersonPicker переводится в layout-пиксели с учётом zoom.
При крайне коротком viewport и 200% окно может перекрыть своё поле через штатный
`coverTarget`, чтобы оставить хотя бы одну читаемую строку; обычное положение
не меняется. Подписи ЦА/регионов остаются на одной строке и адаптируются к ширине.

## Ограничения

Это прямое исключение владельца из правила «только transform/opacity»:
анимируется реальная высота/ширина одного окна через WAAPI, **без масштаба текста**,
blur, копий DOM, React-render на кадрах и сохранения фиксированного размера.
Продолжительность — общий `--ws-motion-normal` (220 мс), ограничение 160–260 мс;
общая кривая `--ws-ease`, без пружин. Действия и ввод не ждут перехода.

Размер до переключения хранится наблюдателем. При повторном переключении
переход начинается с текущей видимой геометрии в layout-пикселях (в том числе
при 200% CSS zoom, без удвоения размеров). Собственный эффект ненадолго
отсоединяется синхронно для измерения естественного размера; одинаковая цель
не перезапускает анимацию. Собственные ResizeObserver-события игнорируются.
После окончания вновь работают CSS auto/max-height и внутренняя прокрутка.
Прямой Fluent DialogBody меняет высоту синхронно с рамкой: его grid/flex
распределяет место прокручиваемому содержимому, чтобы оно не вылезало за окно.
Первое открытие остаётся на существующем lifecycle Fluent.

Reduced motion, forced colors и скрытие отменяют движение. При ручном resize
viewport и перетягивании штатной ручки textarea применяется итог сразу.
Unmount освобождает наблюдателей, кадры и события. Для специализированного
окна предусмотрены `data-dialog-resize-motion="off"` и
`data-surface-resize-motion="off"`; нестандартная плавающая поверхность может
явно включиться через `data-surface-resize-motion="on"`.

[Emil Design Engineering](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md)
прочитан через Lazyweb: использованы короткая длительность, общая кривая,
прерываемость и уважение системных настроек. Запрет height/width сознательно
переопределён явным запросом владельца, а не распространён на весь интерфейс.

Проверки: адресные тесты контроллера, TypeScript/ESLint, браузерный сценарий
`scripts/dialog-resize-motion-smoke.cjs` с временными ответами тестового сайта
и блокировкой бизнес-записей. Последнее уточнение проверяется на настоящих
компонентах в изолированной странице `tmp/popover-resize`: пустой/полный список,
окно вверх/вниз, 100 сотрудников, поиск, compact viewport, 200% и reduced motion.
