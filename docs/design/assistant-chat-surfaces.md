# Чаты ассистента и разделение поверхностей

## Поведение

- Правый клик или Shift+F10 на чате открывает штатное меню Fluent: закрепить/открепить, удалить.
- Меню не переключает текущую переписку. В компактном режиме те же действия доступны через кнопку «…».
- Закрепление хранится в базе отдельно для каждого сотрудника; закреплённые чаты идут первыми.
- Удаление подтверждается отдельно, затем удаляет запись чата и очищает его содержимое и ссылки. При ошибке удаления чат и черновик остаются.
- Удалённый первый чат не создаётся повторно рядом с оставшимися. Если удалён последний чат, создаётся новый пустой с другим идентификатором.
- Пустые технические записи времени запросов сохраняются для защиты часового лимита ИИ; текста, черновиков и ссылок в них нет.
- Сворачивание бокового списка в развёрнутом ассистенте сохраняет активный чат и несохранённый ввод.

## Серверная совместимость

Новые маршруты: `PATCH /api/v1/assistant/chats/{id}/pin` и `DELETE /api/v1/assistant/chats/{id}`. Оба проверяют владельца и возвращают актуальный список. Старый маршрут очистки сообщений сохранён для совместимости. Перед обновлением API нужна добавочная миграция `0082_assistant_chat_pins`; существующие чаты не удаляются. Обновлять только веб-клиент для проверки постоянного закрепления/удаления недостаточно.
