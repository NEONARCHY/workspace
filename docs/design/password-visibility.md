# Один переключатель пароля — 8 октября 2026

На экране входа, активации приглашения и сброса доступа видимость пароля управляется существующей доступной кнопкой. Только эти поля помечены `auth-password-input`: встроенный значок Edge скрыт через `::-ms-reveal`, чтобы два независимых переключателя не появлялись одновременно. Остальные поля пароля не затронуты.

Маскировка по умолчанию, `current-password` / `new-password`, автозаполнение, локальный ввод, TOTP и отправка форм сохранены. Кнопка имеет `type="button"`, доступное имя и `aria-pressed`; переключение не отправляет форму и не теряет ввод. Проверки используют только синтетический пароль.

Основание: [официальная документация Edge](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/password-reveal).
