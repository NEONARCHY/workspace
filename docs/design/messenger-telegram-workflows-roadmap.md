# Мессенджер: компактные сообщения и надёжные действия

**Ветка:** `codex/messenger-telegram-workflows`  
**Статус:** реализовано и проверено локально; ожидает review/merge  
**Правило готовности:** пункт закрывается только после проверки UI, API и сценария синхронизации.

## Пакеты работы

- [x] **MSG-P1 — Типографика и геометрия.** Сохранён фирменный Gilroy с системным fallback для отсутствующих узбекских глифов; служебные иконки получили самостоятельные читаемые размеры.
- [x] **MSG-P2 — Компактные сообщения.** Входящие сообщения придвинуты к рабочему краю, время встроено справа в последнюю строку, лишняя высота пузырей убрана.
- [x] **MSG-P3 — Контекстные действия.** Реакция появляется через секунду наведения, мгновенно исчезает при уходе и не создаёт горизонтальный скролл; собственные сообщения также поддерживают реакции. Ответ, пересылка, закрепление, задача, изменение и удаление доступны через ПКМ и клавиатуру.
- [x] **MSG-P4 — Упоминания.** Ввод после `@` динамически фильтрует участников по имени и логину; список показывает аватары, а выбор сохраняет корректный ID.
- [x] **MSG-P5 — Вложения и голос.** Файлы отправляются без фиктивного текста, голосовые загружаются и подгружаются для прослушивания по запросу; ошибки остаются видимыми для повторной попытки.
- [x] **MSG-P6 — Отложенное удаление сообщений.** Удаление остаётся локальным шесть секунд и допускает отмену; запрос на сервер выполняется только после таймера.
- [x] **MSG-P7 — Удаление чатов.** Создатель/владелец, администратор и суперадминистратор могут удалить допустимый чат с шестисекундной отменой; сервер повторно проверяет права и хранит аудит.
- [ ] **MSG-P8 — Проверка и поставка.** Целевые тесты, lint/typecheck, миграция и ручной web-сценарий проверены. Пункт закрывается после push ветки и создания PR; полный локальный Python integration требует отсутствующей зависимости `cryptography`.

## Контрольные сценарии

1. Кириллица, действующие узбекские апострофы и планируемые буквы отображаются без tofu/подмены всей фирменной типографики.
2. При вводе `@ба`, `@аз` или части логина список сразу сужается и не показывает неподходящих сотрудников.
3. До завершения шестисекундного таймера другой клиент продолжает видеть сообщение или чат; «Вернуть» отменяет запрос без серверной мутации.
4. После истечения таймера сервер повторно проверяет полномочия и публикует событие синхронизации.
5. Голос и обычный файл доступны после обновления страницы и на другом компьютере, подключённом к тому же серверу.
