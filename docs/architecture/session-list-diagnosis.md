# Повторяющиеся сеансы — диагностика 2026-09-04

Список «Активные устройства» фактически показывает серверные сеансы, а не уникальные физические компьютеры. Одинаковые названия сами по себе не позволяют определить устройство или владельца входа.

## Подтверждённые причины

- `workspace-api.ts`: обычный вход отправляет фиксированное `deviceLabel: "Windows desktop"`; постоянного идентификатора установки в этом запросе нет.
- `auth_service.py`, `login_with_password` / `_create_session`: каждый успешный вход создаёт новый UUID сеанса. `refresh_session` обновляет токен существующего сеанса, не создаёт новый.
- `App.tsx`: авторизация хранится в памяти React. Закрытие окна теряет клиентское состояние; серверный сеанс отзывается при явном выходе через `/auth/logout`, не при закрытии окна.
- `list_user_sessions` возвращает неотозванные, ещё не истёкшие записи. В настройках по умолчанию срок refresh-сеанса — 30 дней; это значение по умолчанию, не отдельная проверка конфигурации запущенного сервера.
- Предыдущие проверки интерфейса создавали реальные входы локальной тестовой учётной записи и закрывали тестовые окна без выхода. Это также накапливало записи. По одному названию и скриншоту нельзя приписать тестам каждую конкретную запись.

## Границы текущего изменения

По запросу выполнена диагностика, а не переработка авторизации. Старые сеансы пользователя не отзываются, не скрываются и не объединяются по названию. Сервер и БД не меняются.

Перед текущей проверкой логотипа `scripts/branding-smoke.cjs` получил обязательную очистку только собственного нового тестового сеанса в `finally`, включая проверку отказа доступа после отзыва. Это не исправляет накопление при обычных повторных входах и не распространяется автоматически на остальные smoke-скрипты.

## Предлагаемое отдельное приращение

После согласования: различать установки и сеансы, использовать безопасное сохранение авторизации в Electron, показывать понятные сведения о входах и перенести гарантированную очистку собственных QA-сеансов во все сценарии. Не объединять разные устройства по строке `Windows desktop`; не отзывать посторонние сеансы автоматически.
