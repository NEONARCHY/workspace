# Отсутствия

Модуль `absences` фиксирует отпуск, личное отсутствие, опоздание, больничный и
рабочее мероприятие. Сотрудник указывает точный интервал и причину; сервер
направляет заявку назначенному непосредственному руководителю.

Отпуск, отгул и мероприятие согласуются или отклоняются, а больничный и
опоздание руководитель подтверждает как полученные. Отказ требует комментарий.
Подтверждённые интервалы не пересекаются друг с другом и утверждёнными поездками.

Для больничного сотрудник прикладывает заключение не позднее трёх рабочих дней
после окончания. Файл доступен только сотруднику и admin/superadmin; в сводке
председателя есть только статус и период. Председатель получает общую сводку
через индивидуальное право `absences.admin`; менеджер видит только прямых
подчинённых.

## Список сотрудников из сводки

Каждая из семи плашек открывает центрированное окно только для своего статуса,
включая пустой список. Окно использует текущую сводку, справочник и уже доступные
пользователю заявки: новых полномочий и запросов к скрытым причинам нет.
Причина связывается только с единственной подтверждённой заявкой того же
сотрудника, типа и точного интервала. Историческая, ожидающая или неоднозначная
заявка не подставляется. Согласующий берётся из события `approve`, а для
больничного/опоздания — `acknowledge` с подписью «Получение подтвердил(а)».
Назначенный руководитель не заменяет фактического участника события.
Если подробности недоступны, показываются ФИО, аватарка, известный период и
честное обозначение ограничения. Медицинские вложения здесь не открываются.

«На работе» в этой сводке означает отсутствие действующего подтверждённого
отсутствия, а не отметку начала рабочего дня. Текущий `presence_summary`
не формирует статус `trip`; плашка поездок сохраняет серверный счётчик и
открывает пустой список, не вычисляя поездки по несогласованным данным.

Оформление следует существующим Gilroy, navy/turquoise и мягким оттенкам
плашек. [Frontend Design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
повлиял на иерархию сведений, сдержанность и проверку реального рендера.
Fluent удерживает фокус, Escape закрывает окно и возвращает фокус на плашку;
длинные ФИО и причины переносятся, список прокручивается отдельно от закрытия.

Высота сводки ограничена 640 px и доступной высотой окна с отступами;
сама область списка — максимум 400 px. Flex-компоновка уменьшает только список,
не заголовок и нижнюю кнопку. Процентные границы учитывают также CSS zoom.
Обычные строки уплотнены до примерно 62 px, промежутки — 8 px;
длинные должности, периоды, причины и история согласования не обрезаются.
`scrollbar-gutter: stable` сохраняет ширину строк, а фокусируемая область
поддерживает клавиатурную прокрутку. Права и сопоставление заявок не изменены.
