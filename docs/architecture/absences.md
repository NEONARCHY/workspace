# Отсутствия

Модуль `absences` фиксирует отпуск, личное отсутствие, опоздание, больничный и
рабочее мероприятие. Сотрудник указывает точный интервал и причину; сервер
направляет заявку назначенному непосредственному руководителю.

Отпуск, отгул и мероприятие согласуются или отклоняются, а больничный и
опоздание руководитель подтверждает как полученные. Отказ требует комментарий.
Подтверждённые интервалы не пересекаются друг с другом и утверждёнными поездками.

Для больничного сотрудник прикладывает заключение не позднее трёх рабочих дней
после окончания. Файл доступен только сотруднику и admin/superadmin; в сводке
председателя есть только статус и период. Председатель получает общую сводку
через индивидуальное право `absences.admin`; менеджер видит только прямых
подчинённых.
