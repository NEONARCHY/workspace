# Маршруты проектов

Проекты используют самостоятельный шаблон процесса `project`. Его черновик, опубликованные версии, узлы и связи не пересекаются с шаблонами `payment` и `trip`.

Конструктор открывается во вкладке «Конструктор маршрутов» на экране проектов и повторяет графовый интерфейс заявок на оплату: библиотеку блоков, карту связей, перетаскивание, масштабирование, инспектор назначений, undo/redo, сохранение черновика и отдельную публикацию. Клиент при любом сохранении передаёт исходный ID проектного шаблона; сервер повторно проверяет административные права и валидность связного графа.

Опубликованная версия неизменяема. После публикации сервер создаёт следующий проектный черновик, а шаблоны поездок и оплат остаются без изменений.
