# Форматирование сообщений, цитаты и закрепы

Сообщение сохраняет обычный `body` и отдельные `entities`: тип, начало и длина
в UTF-16 (совместимо с выделением браузера). Поддерживаются bold, italic,
underline, strikethrough, code, quote и link. Произвольный HTML не принимается
и не отображается. Ссылки допускают только абсолютные HTTP(S)-адреса;
открываются с `noopener noreferrer`. Пересылка сохраняет весь текст и его
форматирование. Версии сообщений содержат неизменяемые снимки форматирования.

Редактор поддерживает ПКМ по выделению, Ctrl+B/I/U, Ctrl+Shift+X (зачёркивание),
Ctrl+Shift+M (моноширинный), Ctrl+Shift+. (цитата), Ctrl+K (ссылка),
Ctrl+Shift+N (снять форматирование). Enter отправляет; Ctrl+Enter/Shift+Enter
добавляют строку. IME не вызывает команды. Черновик и форматирование
сохраняются вместе, включая восстановление после ошибки отправки.

`replyQuote` содержит только выбранный текст и его UTF-16-смещение. Сервер
сверяет фрагмент с доступным исходным сообщением в том же чате при отправке.
При чтении цитата не выдаётся, если источник удалён или скрыт политикой истории.
Действия «Переслать» и «Закрепить» всегда относятся ко всему сообщению.

Снятие закрепа имеет `scope=all|self`. Для всех требуется прежнее право
управления сообщениями. Для себя доступно обычному участнику: сервер сохраняет
личное скрытие, не меняя общий закреп. Повторное новое закрепление снова видно.

Закреп, созданный председателем (существующая проверка executive position),
получает постоянную защиту. Она не снимается после смены должности. Текущие
закрепы действующего председателя также защищены; миграция не утверждает,
что историческая должность автора закрепа известна. Повторное закрепление
идемпотентно и не подменяет создателя. Нельзя скрыть защищённый закреп для себя,
снять для всех или обойти запрет удалением сообщения. Операции сериализованы
существующей блокировкой чата и записываются в аудит.

## Обновление

Сначала API и добавочная миграция `0100_messenger_rich_text`, затем web/desktop.
Миграция добавляет поля и таблицу личных скрытий; сообщения и версии не удаляет.
Офисное развёртывание требует отдельного согласования. Старые клиенты читают
plain body, но не умеют новое форматирование: для полноценной работы нужен
обновлённый клиент.
