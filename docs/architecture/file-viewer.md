# Встроенный просмотр вложений

Общий FileViewer открывается из стандартных вложений мессенджера, задач,
заявок и сохранённых документов AI Referent. Чтение не изменяет оригинал;
скачивание остаётся отдельным действием в просмотрщике. Входящие письма ЭДО используют
тот же интерфейс через ExternalFileViewer и собственные защищённые маршруты, не
подменяя идентификаторы общих вложений. Подробнее: [ЭДО](edo-incoming.md).
Документы импорта проектов и подписанные пакеты референта сохраняют прежние
собственные действия: это не вложения общего хранилища.

## Форматы и UX

В форме AI Referent выбранное, ещё не сохранённое письмо и приложения открываются
по названию/иконке через LocalFileViewer. PDF, изображения и медиа читаются непосредственно
из выбранного File. Для Office POST `/ai-referent/file-preview` требует сессию и право
просмотра модуля, ограничивает вход 25 МиБ и параллельность двумя запросами, использует
тот же защищённый парсер. Маршрут не записывает письмо, объект в хранилище, задание роботу
или результат проверки подписи. Закрытие отменяет запрос и освобождает preview URL.
Отдельная существующая проверка документа роботом сохраняет прежнее поведение.

- DOCX: текст и таблицы в исходном порядке, масштаб и поиск по содержимому.
  Встроенные картинки и сложное оформление Word не воспроизводятся.
- XLSX: имена листов, страницы по 200 строк, до 80 колонок, закреплённые
  заголовки и номера строк. Поиск относится к загруженной странице, не всей книге.
  Читаются сохранённые результаты формул; если результата нет, показывается
  формула как текст. Формулы не пересчитываются.
- PDF: отдельный lazy chunk PDF.js 5.5.207 и локальный worker, одна страница
  на canvas, предыдущая/следующая страница, масштаб и доступный текстовый режим.
  Bitmap ограничен 8 млн пикселей и 8192 px по стороне; чрезмерные размеры
  страницы отклоняются. Прежняя задача отрисовки отменяется и ожидается
  перед использованием того же canvas. Документ/worker уничтожаются при закрытии.
  Скрипты и интерактивные PDF-действия не запускаются: используется только
  API отрисовки и извлечения текста, `isEvalSupported: false`.
  Nginx отдаёт module-worker `.mjs` с JavaScript MIME, сохраняя nosniff и CSP.
- Фото: масштаб 50–300%, поворот, адаптация под область просмотра и прокрутка
  увеличенного изображения. SVG отображается только через img, не как HTML.
- Видео: нативный HTML5 player, без autoplay; аудио использует существующий
  плеер Workspace с громкостью и обложкой MP3. Неподдерживаемый codec показывает
  ошибку с сохранённой возможностью скачать оригинал. При закрытии аудио/видео
  явно приостанавливаются, src удаляется и media element очищается через load.
- DOC/XLS и неизвестные типы скачиваются, без обещания встроенного чтения.

Просмотрщик использует WorkspaceDialog, Fluent, Inter и существующие токены.
Esc, focus restoration, reduced motion и forced colors сохраняются. Фото в
мессенджере сохраняют превью: оно загружается только в видимой области,
отменяется и освобождается при уходе за viewport. Остальные файлы не загружаются
всем списком. Голосовые сообщения продолжают использовать прежний voice player.

## API и безопасность

`GET /api/v1/attachments/{id}/preview?sheet=0&offset=0` возвращает типизированное
OfficeFilePreview. Общий helper загрузки проверяет get_attachment и право view
соответствующего модуля до обращения к storage, как обычное скачивание.
Оба ответа используют `Cache-Control: private, no-store`; новые права не выдаются.

Существующие проверки Office ZIP ограничивают размер, число записей и заполненных
ячеек; макросы, зашифрованные архивы и внешние ссылки Excel отклоняются. XML
читает defusedxml, содержимое показывается React-текстом, без HTML-injection.
Word XML дополнительно ограничен 4 МБ; вывод — 2000 блоков и 350000 символов.
Для больших/обрезанных документов интерфейс явно предлагает оригинал.
Два параллельных чтения/разбора на процесс API ограничиваются semaphore;
разбор выполняется в thread, не блокирует event loop. Постоянного preview-кэша нет.

Закрытие или смена страницы отменяет клиентский запрос. Общий boundedRequest
сохраняет abort/timeout до чтения тела ответа, а не только до получения заголовков;
HTTP-ошибка не запускает failover. Неактуальные ответы не обновляют интерфейс,
object URLs освобождаются. Файлы не отправляются Microsoft/Google и другим сервисам.

## Проверка и выпуск

FileViewer.test, workspace-api.test, AttachmentPanel.test покрывают классификацию,
безопасный текст, таблицы, поиск, страницы/листы, retry, late responses, URL cleanup,
ошибки аудио и отмену загрузки после получения заголовков. Python test_file_preview
проверяет реальные DOCX/XLSX, формулы и запреты доступа до чтения storage.
QA page-canvas содержит только синтетические файлы и подставные Office-ответы:
проверка макета не доказывает фактический запуск серверного парсера.

Для Office необходимы обновления API и web/desktop вместе; миграций нет.
В локальном окружении pytest и types-defusedxml не установлены: Python runtime
тесты и полный mypy пока не подтверждены. Ruff пройден. Упакованный Electron
и настоящий LAN-сайт пока не проверены; сервер не обновлялся.

PDF API: https://mozilla.github.io/pdf.js/examples/
Версия выбрана совместимой с Node 20 и вне диапазона GHSA-hq66-cqwq-w95j;
после установки `pnpm audit --prod --audit-level high` не нашёл известных уязвимостей.
