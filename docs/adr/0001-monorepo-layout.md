# ADR-0001: локальный монорепозиторий как первый фундамент

- **Статус:** принято
- **Дата:** 2026-09-02

## Контекст

Первый релиз объединяет desktop-клиент, API, фоновые процессы, инфраструктуру и поэтапную миграцию старых приложений. Общие контракты, безопасность и тесты должны меняться согласованно. Удалённый Git-hosting и его владелец пока не выбраны.

## Решение

Создать локальный Git-монорепозиторий в `Yuksalish Workspace` со структурами `apps`, `modules`, `packages`, `infrastructure`, `tests` и `docs`. JavaScript workspace управляется pnpm; Python-пакеты устанавливаются одним `pyproject.toml`. Production-снимки и секреты остаются вне Git.

Первый рабочий vertical slice включает:

- FastAPI health и каталог модулей;
- sandboxed Electron shell с тремя локалями;
- Docker Compose для PostgreSQL, Redis, MinIO, API, worker, scheduler и gateway;
- Alembic import ledger;
- read-only инспектор и versioned mapping Hisobot.

## Последствия

- Контракты и проверки запускаются одной командой.
- Desktop и backend остаются технологически независимыми, но версионируются вместе.
- Репозиторий можно позже опубликовать в выбранном приватном Git-hosting без переноса структуры.
- Branch protection невозможно доказать до создания удалённого репозитория; пока правило зафиксировано документально и в CI.
