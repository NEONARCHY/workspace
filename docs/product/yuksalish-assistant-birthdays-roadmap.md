# Ассистент Yuksalish и дни рождения

План для текущей тестовой версии. Ключ Gemini хранится только на сервере; сотруднику доступны лишь его собственные диалоги и разрешённые рабочие данные.

- [x] Виджет ассистента во всех разделах, три UI-компонента, выбор модели и адаптивность.
- [x] Серверный Gemini-шлюз, сохранение личной истории и защищённый контекст рабочих задач.
- [x] Настройка дня и месяца рождения, ежегодная запись в ленте и уведомления коллегам без дублей.
- [x] Генерация короткого личного поздравления с выбором русского или узбекского языка.
- [x] Серверные и целевые UI-тесты, проверка на едином тестовом сайте и скриншоты сценариев.

Известное ограничение общего UI-набора: прежний тест редактирования сообщения в мессенджере
проходит отдельно, но после других сценариев мессенджера превышает лимит времени. Остальные
331 из 332 UI-тестов проходят; это требует отдельной стабилизации и не включено в данный пакет.
