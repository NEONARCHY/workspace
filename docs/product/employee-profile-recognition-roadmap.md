# Профиль сотрудника и признание заслуг

## Цель

Единый публичный профиль сотрудника открывается по имени или аватару из рабочих
карточек. Он показывает только служебные сведения: должность, участие в проектах,
задачах и поездках, объяснимую эффективность, стаж и награды.

## Этапы

- [x] Акцентные hover-состояния действий в согласовании поездок.
- [ ] Общий кликабельный элемент сотрудника во всех рабочих карточках и диалог профиля.
- [ ] Серверный агрегат профиля с объектными проверками доступа.
- [ ] Редактируемая кадровая история и дата начала работы для администратора и позиции
  `Inson kapitali bo‘yicha bo‘lim`.
- [ ] Каталог из шести наград, выдача автором после принятия результата задачи и
  постоянная выдача руководителем или кадровой службой.
- [ ] Уведомление о награде, доступная праздничная анимация и спокойная loop-анимация
  наград с поддержкой `prefers-reduced-motion`.
- [ ] API, миграция, аудит, тесты прав и визуальная проверка.

## Ограничения

Публичный профиль не показывает логин, контакты, данные авторизации, личные чаты,
административные заметки и другие конфиденциальные сведения. Награда после задачи
может быть выдана только постановщиком принятой задачи и только исполнителю этой задачи;
повторная награда того же типа за ту же задачу запрещена.
