# Передача пакета интерфейса и мессенджера — 16.10.2026

Пакет объединяет накопленные изменения владельца: компактные голосовые сообщения,
стабильный composer и запись, переносы строк, satin-обводки, маски раскрытия,
анимацию и геометрическую совместимость тем, контекстные skeleton с задержкой
250 мс, просмотр документов непрерывной лентой, карту поездок, расположение
подсказок и действий drawer, историю задач и пояснение просрочек, форматирование
сообщений, выбранные цитаты и личные/защищённые закрепы. Независимые заметки
обновлений сохранены в pending; прежние номера и consolidation не изменялись.

## Продолжение на другом компьютере

Получить проверенный `origin/main` после слияния пакета из
`fix/messenger-compact-voice-bubbles`. API обновлять до web/desktop: требуется
добавочная миграция `0100_messenger_rich_text` после `0099_merge_attachment_trip_heads`.
Перед обновлением сервера сделать резервную копию БД и проверить применённые
миграции. Перед Docker web build заново выполнить prepare-release-note-order.
Push/merge не обновляет установленный Electron EXE.

Владелец разрешил обновить только локальный TEST (`https://192.168.0.127:8443/`).
Офисный сервер `workspace.opinions.uz` в этом пакете не обновлять. Разрешение на
офисную миграцию и замену установленного клиента запрашивается отдельно.

## Следующая ручная проверка

Автоматические проверки не заменяют браузерную и установленную Electron-проверку.
Проверить в обеих темах, при 1024×768/200%: семь видов форматирования и undo/redo,
IME и русскую раскладку хоткеев, Ctrl/Shift+Enter, ПКМ по фрагменту, безопасные
ссылки, восстановление после ошибки, пересылку всего сообщения, личный и общий
закреп, запрет снятия закрепа председателя, поведение ограниченной истории.
Отдельно проверить реальные размеры skeleton, анимации окон/тем, первую страницу
PDF/DOCX и скругления карты. В этой сессии браузерный инструмент не запускался;
точное визуальное соответствие и 60 fps не подтверждены.
