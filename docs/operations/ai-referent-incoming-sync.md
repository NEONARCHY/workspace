# Синхронизация входящих AI Referent

Bridge запускается на ПК референта рядом с установленным роботом. Он только читает
`robot_state.sqlite` и `register.xlsx`, отправляет реестровые поля в Workspace и не
изменяет локальную базу робота.

## Подготовка сервера

1. Обновить код и применить миграции: `alembic upgrade head`.
2. Создать длинный случайный секрет минимум 32 байта и передать его серверу только через
   переменную `YUKSALISH_AI_REFERENT_AGENT_TOKEN`.
3. Перезапустить API. PostgreSQL и MinIO должны быть доступны API внутри Docker-сети.
4. Не публиковать PostgreSQL, Redis или MinIO в локальную сеть ради этой интеграции.

## Первый безопасный запуск на ПК референта

Задать переменные только в защищённой пользовательской среде Windows или в Credential
Manager-обёртке; не записывать токен в репозиторий или `.bat`:

```powershell
$env:YUKSALISH_API_BASE_URL = "https://SERVER/api/v1"
$env:YUKSALISH_AI_REFERENT_AGENT_TOKEN = "<секрет с сервера>"
python scripts/sync_ai_referent_incoming.py --ca-file C:\path\workspace-ca.pem
```

Если робот использует стандартные пути `C:\EXAT_ROBOT_MALUMOTLAR`, дополнительные
аргументы не нужны. Для нестандартной установки указать `--database` и `--journal`.
Самоподписанный HTTPS-сертификат нельзя обходить отключением проверки: передайте CA-файл.

После проверки одноразового запуска bridge можно держать в цикле:

```powershell
python scripts/sync_ai_referent_incoming.py --watch --interval 60 --ca-file C:\path\workspace-ca.pem
```

Для production предпочтительнее Windows Task Scheduler или служба с отдельным
неадминистративным пользователем и политикой перезапуска. Команда не содержит секрет.

## Проверка

- во вкладке «Входящие» появляется таблица писем;
- время «Последняя синхронизация» обновляется;
- «Excel-журнал» скачивает последнюю копию `register.xlsx`;
- повторный запуск сообщает строки как `unchanged`, не создавая дублей;
- имя ответственного показывается как получено от робота до будущего сопоставления с
  аккаунтом Workspace.

Excel также по-прежнему открывается локально кнопкой «Excel входящих» в интерфейсе
самого робота. Архивы писем и вложения этим этапом не переносятся.
