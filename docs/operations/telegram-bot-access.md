# Доступ сотрудников к Telegram-ботам

Раздел «Доступ к Telegram-ботам» виден только администраторам Workspace. Он показывает
действующих сотрудников, один личный Telegram ID на человека и отдельные разрешения
по ботам. Это не замена правам модуля AI Referent: согласующего по-прежнему назначают
на вкладке «Согласующие» или в GUI Exat.

## Ввод в эксплуатацию

1. Сделать резервную копию PostgreSQL. Не удалять базу или Docker volumes.
2. Обновить API и применить миграцию `0052_telegram_bot_access` обычной командой
   `alembic -c apps/api/alembic.ini upgrade head` в серверном окружении проекта.
3. Обновить web/desktop-клиент отдельно: Git push не обновляет установленные версии.
4. Под администратором открыть новый раздел. Ранее подтверждённые Telegram-привязки
   и ID действующих согласующих перенесены с доступом к AI Referent, чтобы не
   прервать текущую работу. Проверить эти назначения и отозвать лишние.
5. Для нового сотрудника указать числовой личный Telegram ID, отметить AI Referent и
   сохранить. ID и разрешение действуют сразу: одноразовый код и `/link` не нужны.
   Сотрудник должен сам открыть чат с ботом и нажать «Старт», чтобы Telegram позволил
   боту отправлять ему уведомления.

Смена ID немедленно отключает старый ID. Снятие галочки AI Referent немедленно
отключает доступ к этому боту, но не удаляет назначенный ID и не меняет историю
писем. Увольнение/деактивация аккаунта также блокирует доступ на сервере.
Повторное сохранение старой версии строки получает конфликт 409; обновите список,
сравните значения и сохраните снова.

Hisobot, Takliflar va Murojatlar, Hudud AI Reyting и AI News Reader уже указаны в
каталоге как направления для будущей интеграции. Их флажки сохраняют намерение
администратора, **но пока не управляют входом в соответствующие отдельные боты**.
Подключать их можно только после реализации проверки центрального ID и grant в
каждом боте; не объявляйте эти флажки действующим контролем доступа.

Подготовка этой версии кода не меняет работающий сервер, Docker, ПК референта или
локальные папки других ботов. Обновление робота Exat требуется только для нового
текста подсказки; серверная проверка прав начинает работать после обновления API.
