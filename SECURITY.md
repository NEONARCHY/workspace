# Безопасность

Не помещайте в issues, коммиты или pull requests токены, пароли, Telegram ID, ФИО сотрудников, production-базы и рабочие документы.

При обнаружении секрета:

1. прекратите его распространение;
2. уведомите администратора внутренним каналом;
3. согласованно замените секрет на всех активных узлах;
4. удалите секрет из истории Git специализированным инструментом;
5. зафиксируйте инцидент и проверку отсутствия повторной утечки.

Старые боты продолжают работать до отдельного cutover. Не вращайте их токены без согласованного окна, иначе действующий сервис остановится.
